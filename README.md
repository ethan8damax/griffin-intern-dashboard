# Griffin Intern Dashboard

Intern Analyst KPI & Metrics Dashboard — Scorecard, Journal, Goals & OKRs, Reviews, and Reference tabs, for the Griffin Global / Doeren Mayhew engagement.

See `CLAUDE.md` for architecture notes and known shortcuts (localStorage persistence, mocked Jira sync).

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
